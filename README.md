### 🧪 Things I'm building

**YouTube Creator Finder**
A Python and Claude tool that searches YouTube by content rather than channel name, ranks creators against a plain-English brief using real engagement and relevance signals, finds contact emails where that's legitimately possible, and writes the whole shortlist into a Google Sheet. Built to speed up sourcing for creator and affiliate outreach.
*Stack: Python, Claude API, Google Sheets API. Private for now.*

**Ad hook analyzer**
A Claude skill that studies proven, high-performing ad hooks, breaks down why they work, and helps generate new hook variations to iterate faster on paid social concepts.
*Stack: Claude Skill. Private for now.*

More of these will move from private scripts to public repos as I clean them up. Happy to talk through how either one works if you're curious.
